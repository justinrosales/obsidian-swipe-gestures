# Contributing

Thanks for helping improve Horizontal Swipe Gestures. Bug reports, documentation fixes, and focused code contributions are welcome.

## Before you start

- Search the existing issues before opening a new one.
- For a bug, describe the behavior you expected, what happened instead, your Obsidian version, and your operating system.
- Open an issue before starting a large change so its scope and approach can be discussed.
- Never include vault content, personal settings, or other private data in an issue or pull request.

## Development setup

You need:

- Node.js 18 or later
- npm
- A desktop installation of Obsidian for manual testing

Clone the repository, switch to the development branch, and install the locked dependencies:

```bash
git clone https://github.com/justinrosales/obsidian-swipe-gestures.git
cd obsidian-swipe-gestures
git switch develop
npm ci
```

Create a focused branch from `develop`. Use a name that describes the change, such as:

```bash
git switch -c fix/swipe-direction
```

Use `develop` as the base branch for contributions. The `main` branch is reserved for release-ready changes.

## Development commands

Start esbuild in watch mode while developing:

```bash
npm run dev
```

Run the required checks before submitting a change:

```bash
npm run lint
npm run build
```

`main.js` is generated by esbuild. Do not edit it by hand or include generated changes in a contribution unless a maintainer specifically requests them.

## Test in Obsidian

Obsidian loads a plugin from a folder under `<vault>/.obsidian/plugins/`. For manual testing:

1. Place the repository in `<vault>/.obsidian/plugins/horizontal-swipe-gestures/`.
2. Run `npm run build`.
3. Reload Obsidian.
4. Enable **Horizontal Swipe Gestures** in **Settings → Community plugins**.
5. Exercise the behavior affected by your change.

For gesture changes, test both swipe directions, custom command mappings, **Invert direction**, sensitivity, and horizontal dominance. Also reload or disable the plugin and confirm that it leaves no stale UI or event behavior behind.

This plugin is desktop-only, so test with a trackpad or input device that produces horizontal wheel events.

## Code guidelines

- Write strict TypeScript and handle errors gracefully.
- Keep `src/main.ts` focused on plugin lifecycle and registration. Put substantial new behavior in a focused module under `src/`.
- Use Obsidian's `register*` helpers for listeners, timers, and other resources that require cleanup.
- Keep startup work light and avoid unnecessary vault scans or disk writes.
- Avoid Node.js or Electron APIs unless the feature genuinely requires them.
- Do not add network requests, telemetry, or external services without prior discussion and clear user-facing disclosure.
- Keep user-facing text concise and use sentence case.
- Do not include `node_modules`, personal `data.json`, source maps, or unrelated formatting changes.

## Submit a contribution

Keep each contribution focused. In its pull request description:

- Explain the problem and the approach taken.
- Link any related issue.
- Describe how you tested the change.
- Include screenshots or a short recording when the user interface changes.
- Confirm that `npm run lint` and `npm run build` pass.

Open the pull request against `develop`. A maintainer will review it and may ask for changes before merging.

Do not update version numbers, `versions.json`, or release notes unless the contribution is specifically preparing a release.
